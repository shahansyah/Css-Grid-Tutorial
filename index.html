Basic Concepts of CSS Grid

CSS Grid Layout (atau cukup disebut CSS Grid) adalah sistem tata letak (layout system) berbasis dua dimensi (2D) di CSS. Berbeda dengan Flexbox yang berfokus pada satu arah saja (baris atau kolom), CSS Grid dirancang untuk menangani baris (rows) dan kolom (columns) secara bersamaan. Hal ini memudahkan kita dalam membuat struktur halaman web yang kompleks dan responsif tanpa perlu menggunakan trik floats atau positioning yang rumit.

CSS Grid Layout (or simply CSS Grid) is a two-dimensional (2D) layout system in CSS. Unlike Flexbox, which focuses on only one direction (rows or columns), CSS Grid is designed to handle rows and columns simultaneously. This makes it easier to create complex, responsive web page structures without having to resort to complicated floats or positioning tricks.

By using CSS Grid, you can create complex, precise, and responsive web page layouts much more easily without having to resort to complicated floats or positioning tricks.

Basic Terminology of CSS Grid

▶ Grid container: Outer boundary (complex area). This is the parent element that wraps all the items inside it. This is where you enable the grid using the display: grid property.

▶ Grid item: Houses within the complex. These are all child elements (direct children) that are directly inside the Grid container.

▶ Grid line: Lot/road boundary lines. Horizontal and vertical lines that form a grid structure. These lines are used as numbering guides when we want to determine the start and end of an element.

▶ Grid cell: One plot of land (the smallest plot). This is the smallest unit within the grid, formed at the intersection of one row and one column (like a single cell in an Excel table).

▶ Grid area: A combination of several grid cells. The total area occupied by an element.

▶ Grid track: A row of streets or a row of lots. A general term used to refer to a full column (vertical) or a full row (horizontal) within a grid.

▶ Grid gap: The empty space or gutter between grid tracks (columns or rows).

So, in CSS Grid, there are two types: Explicit Grid and Implicit Grid.

What is an Explicit Grid?
An Explicit Grid is a grid structure whose dimensions you intentionally define yourself in the CSS code using the grid-template-columns, grid-template-rows, or grid-template-areas properties.
What is an Implicit Grid?
An implicit grid is an additional row or column automatically created by the browser when the number of grid items (child elements) exceeds the capacity of the explicitly defined grid. By default, the browser adds a new row below with its size set to 'auto'. For example, items 10 - 12 use an implicit grid.

Justify-items: start;

Justify-items: center;
Justify-items: stretch;

1. justify-items: start; Effect: Aligns all Grid items to the start/left side of their respective grid cells. Size: The item width shrinks to fit only the text/content (does not fill the cell width).
2. justify-items: end; Effect: Aligns all Grid items to the end/right side of their respective grid cells. Size: The item’s width shrinks to fit its text or content.
3. justify-items: center; Effect: Places all Grid items exactly in the center of the grid cell. Size: The width of the items shrinks to fit their text or content.
4. justify-items: stretch; (Default Value) Effect: Forces all Grid items to stretch to fill 100% of the grid cell’s width.
Note: This effect only works if the items do not have a specifically set `width` property. Remember: `justify-items` is applied to the parent container that has `display: grid;`, not to the elements...
